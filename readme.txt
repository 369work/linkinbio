シンプルな link-in-bio ブロックテーマ。サイトエディターから簡単にカスタマイズできます。

== 必要なもの ==

* WordPress 6.7 以上
* PHP 7.4 以上

== インストール方法 ==

1. linkinbio フォルダを /wp-content/themes/ にアップロードする
2. 管理画面「外観 > テーマ」から「LinkInBio」を有効化する
3. 管理画面「外観 > エディター」でプロフィールやリンクを編集する

== カスタマイズ方法 ==

サイトエディター（外観 > エディター）から以下を編集できます。

* プロフィール名・肩書き・自己紹介文
* SNSリンクのURLとラベル
* CTAボタンのテキストとメールアドレス
* カラー・フォントなどのスタイル

スタイルバリエーション「Glass (Light)」を選ぶと、明るいすりガラス調のデザインに切り替わります。

== トップページの表示について ==

このテーマはトップページにプロフィール／リンク／CTA を表示する front-page テンプレートを採用しています。
そのため「設定 > 表示設定」で固定ページをトップに指定していない場合でも、トップページにはブログの投稿一覧ではなく
プロフィール画面（front-page.html）が優先して表示されます。

ブログの投稿一覧をトップに表示したい場合は、次のいずれかを行ってください。

1. 「設定 > 表示設定」でホームページの表示を「固定ページ」にし、投稿ページを別途指定する
2. または front-page.html をサイトエディターで編集し、投稿一覧（index）のレイアウトに差し替える

なお、カテゴリーやアーカイブ、個別投稿ページは通常どおり投稿一覧・本文を表示します。
